## Design Context

### Users

Polyglot indie hackers and small-team developers who ship across many repos. They
arrive from a link on HN, a dev newsletter, or a GitHub README. They want a fast
answer to "what is gitjoin?", enough detail to trust it, and a low-friction path
to the repo. They respect craft and are allergic to marketing-speak.

### Brand Personality

Precise, plain-text, quietly confident. Feels like a tool recommended by a friend
who has strong taste. Three words: **craft, precision, restraint**. The page
should read like a well-typeset man page, not a product launch.

### Aesthetic Direction

**A traditional landing page on a ruled sheet.** One centered frame with hairline
side rules; sections separated by full-width hairlines with small register marks
where they meet the frame. Faint dot-grid "graph paper" outside the frame.
Reference: the layout of mygo.egoist.dev (slim sticky nav, ruled fact strip,
tabbed code panel, ruled feature grid).

- **Theme**: dark, strictly black and white. Near-black neutrals, off-white text.
  No accent hue: emphasis comes from brightness, weight and inversion (white
  primary button, inverted step number).
- **No** gradients on text. **No** glow. **No** glassmorphism. **No** neon.
- Typography: Schibsted Grotesk (display + body; heavy, tight-tracked headlines)
  paired with Fragment Mono for literal things — commands, paths, file trees and
  small uppercase labels.
- Signature element: the hero "workspace" demo. A file tree whose repo lines are
  cloned by four parallel workers after `gitjoin` is typed. Without JS or with
  reduced motion it renders fully joined.
- Content is real: every claim, flag and output line must match the gitjoin
  source (`bep/gitjoin`). Content lives in `content/_index.md` front matter.

### Anti-references

Generic SaaS homepages, Vercel/Linear clones (dark + cyan/purple gradients +
Inter), corporate consulting pages, cartoonish dev-tool mascot sites.

### Design Principles

1. **Show the tool working.** Real trees, real manifests, real output beat
   adjectives.
2. **Limited navigation.** Three anchor links plus X and GitHub. The GitHub repo
   is always one click away (nav, hero, closing section, footer).
3. **Restraint over flourish.** Hairlines, 2px radii, one primary button per
   view. Decoration only where it reinforces the ruled-sheet metaphor.
4. **Monochrome, done right.** Hierarchy from five neutral steps
   (fg, fg-mute, fg-dim, fg-ghost, rule), never from color.
5. **Mobile is adapted, not shrunk.** Stacked comparison, full-width actions,
   no horizontal page scroll.
